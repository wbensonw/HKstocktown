## 三、 系統架構與資料流規劃

本專案採用 **前頁靜態託管（GitHub Pages） + 後端無伺服器微服務（Cloudflare Workers）** 的全免費架構：

```
[ 瀏覽器端：港股點心茶樓 3D 網頁 (託管於 GitHub Pages) ]
   │  ▲
   │  │ 1. 每 30~60 秒發送 HTTPS GET 請求 (/api/hk-stocks)
   ▼  │ 4. 回傳標準化 JSON (含恆指 ^HSI、熱門港股報價、成交額、異動狀態)
[ 後端微服務：Cloudflare Workers (全球邊緣節點 + 60秒快取解決 CORS) ]
   │  ▲
   │  │ 2. 代為請求 Yahoo Finance v8 Chart / Quote API (無須付費 API Key)
   ▼  │ 3. 取得即時/收盤數據，若 API 限流則自動切換為「高擬真備援模擬數據」
[ 外部數據源：Yahoo Finance 港股公開端點 (^HSI, 0700.HK, 9988.HK...) ]
```

* **為什麼需要 Cloudflare Workers？**
  前端網頁（GitHub Pages）若直接抓取 Yahoo Finance 或港交所資料，會被瀏覽器的 **CORS（跨來源資源共用）安全機制阻擋**。透過 Cloudflare Workers 作為中繼站，不僅能加上 `Access-Control-Allow-Origin: *` 解決跨域問題，還能利用 Cloudflare Edge Cache 快取 60 秒，確保免費額度（每日 100,000 次請求）絕對夠用！

## 五、 新手零基礎保姆級操作指南（提前預覽與實戰流程）

為了讓您在等待 Cursor AI 寫程式的同時心中有數，以下為您整理好整個專案從 **「在電腦生成檔案」** 到 **「免費發布到網路上」** 的 5 個步驟（Cursor AI 也會將這份詳細指南寫進您的 `README.md` 中）：

### 第一步：用 Cursor AI 生成專案並在本地電腦預覽
1. 確保您的電腦已安裝 **Node.js**（若尚未安裝，請前往 [nodejs.org](https://nodejs.org/) 下載「LTS 長期支援版」並一路下一步安裝）。
2. 在電腦桌面建立一個新資料夾 `hk-stock-dimsum`，打開 **Cursor AI** -> `File` -> `Open Folder` 選擇該資料夾。
3. 按 `Ctrl + I`（Mac 為 `Cmd + I`）打開 **Composer / Agent 面板**，選擇 **Grok 4.7** 模型，貼上上方第四節的**「終極開發藍圖提示詞」**。
4. 當 AI 生成完所有檔案後，點擊 `Accept All` 儲存檔案。
5. 在 Cursor 下方打開終端機（Terminal，快捷鍵 `` Ctrl + ` ``），依序輸入以下兩行指令即可在自己電腦瀏覽器看到 3D 港式茶樓：
   ```bash
   npm install
   npm run dev
   ```
   *(點擊終端機出現的 `http://localhost:5173` 網址即可直接體驗！)*

---

### 第二步：免費註冊並建立 Cloudflare Workers（後端港股 API 微服務）
我們甚至不需要使用複雜的終端機指令部署後端，直接用 **Cloudflare 網頁後台「複製貼上」** 是對新手最友善、0 失敗率的方法：
1. **註冊帳號**：前往 [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)，輸入您的 Email 與密碼免費註冊（選擇免費 Free 方案即可，不需綁定信用卡）。記得到信箱點擊驗證信。
2. **建立 Worker**：
   * 登入 Cloudflare 後台，點擊左側選單的 **「Workers & Pages（工作者與頁面）」**。
   * 點擊藍色的 **「Create（建立）」** 按鈕 -> 選擇 **「Create Worker（建立 Worker）」**。
   * 為您的服務取個名字（例如：`hk-dimsum-api`），然後點擊右下角的 **「Deploy（部署）」**。
3. **貼上後端程式碼**：
   * 部署成功後，點擊畫面右上角的 **「Edit code（編輯程式碼）」**。
   * 打開 Cursor AI 幫您生成的 `worker/index.js` 檔案，將裡面的程式碼**全選複製**。
   * 回到 Cloudflare 網頁編輯器，把原本預設的幾行程式碼刪掉，**貼上**剛剛複製的程式碼，然後點擊右上角藍色的 **「Deploy（部署）」**。
4. **取得您的專屬 API 網址**：
   * 部署後，畫面頂部會顯示一串網址（例如：`https://hk-dimsum-api.您的帳號.workers.dev`）。
   * 把這串網址複製起來，告訴 Cursor AI：*「請幫我把前端 `stockService.js` 裡面的預設 Worker 網址改成 `https://hk-dimsum-api.您的帳號.workers.dev`」*，這樣前端就會自動連線到您的雲端微服務了！

---

### 第三步：免費註冊 GitHub 並部署 GitHub Pages（前端 3D 網站）
1. **註冊 GitHub**：前往 [github.com](https://github.com/)，點擊右上角 **「Sign up」**，依指示輸入 Email、密碼與使用者名稱，完成免費註冊。
2. **建立新的儲存庫 (Repository)**：
   * 登入 GitHub 後，點擊右上角的 **`+` 號** -> 選擇 **「New repository」**。
   * **Repository name** 輸入：`hk-stock-dimsum`。
   * 確保下方選擇 **「Public（公開）」**（公開儲存庫才能免費使用 GitHub Pages）。
   * 點擊最下方的綠色按鈕 **「Create repository」**。
3. **開啟 GitHub Pages 自動部署權限**：
   * 在剛建好的 GitHub 儲存庫頁面，點擊上方選單的 **「Settings（設定）」**。
   * 點擊左側選單的 **「Pages」**。
   * 在中間的 **「Build and deployment」 -> 「Source」** 下拉選單中，將原本的 `Deploy from a branch` 改為 **「GitHub Actions」**。
4. **讓 Cursor AI 幫您一鍵上傳程式碼**：
   * 複製您的 GitHub 儲存庫網址（例如 `https://github.com/您的帳號/hk-stock-dimsum.git`）。
   * 回到 Cursor AI 對話框，直接跟 AI 說：
     > *「我已經建立好 GitHub 儲存庫了，網址是 `https://github.com/您的帳號/hk-stock-dimsum.git`，請直接在 Terminal 幫我執行 git init、commit 並 push 到 main 分支。」*
   * Cursor 會自動幫您執行上傳（過程中瀏覽器若跳出 GitHub 登入授權視窗，點擊 Authorize 即可）。
5. **大功告成！取得您的 3D 港股茶樓網址**：
   * 上傳後等待約 1～2 分鐘，回到 GitHub 儲存庫頁面的 **「Actions」** 分頁，看到綠色勾勾 `✅` 後，您的 3D 港式點心茶樓網站就會正式上線於：
     `https://您的GitHub帳號.github.io/hk-stock-dimsum/`！
