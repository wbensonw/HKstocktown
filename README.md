# 恆指大茶樓（第一版）

在瀏覽器裡看一間港式茶樓。恆指做成霓虹燈，最多 15 隻精選港股做成蒸籠。成交越大，蒸氣越密。這是第一版，畫面就停在現在這個樣子。

本機開發仍然用 `npm run dev`。想放到網上給別人看，請看 [DEPLOY.md](DEPLOY.md)。

## 準備

這台電腦的 Node.js 在：

`%LOCALAPPDATA%\node-v24.22.0-win-x64`

如果終端機說找不到 `node`，先關掉終端機再打開一次。其他電腦到 [nodejs.org](https://nodejs.org/) 安裝 LTS 版本。

## 啟動

在這個資料夾打開終端機：

```bash
npm install
npm run dev
```

瀏覽器打開 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。按 `Ctrl + C` 停止。

開發伺服器會在你的電腦上代向騰訊財經取恆指和自選股的報價、30 日紀錄與當日分時，大約每 60 秒更新一次。連不上時，左上角會寫「模擬數據」。

## 畫面怎麼讀

- 霓虹燈跟着恆指升跌。預設綠升紅跌，可以改成紅升綠跌。
- 每桌一隻股票。蒸氣越密，成交越活躍。
- 茶客人數只表示成交活躍，不是真實茶客，也不是買賣盤。
- 中央茶壺代表大市成交。
- 點心車是這批自選股裡的升幅、跌幅、成交額前列，不是全市場榜。
- 後巷洗大餅、大家樂是虛構幽默。恆指下跌時，大家樂的人和隊伍會變多。不構成投資建議。
- 休市時，門口告示牌顯示狀態和距離早市的倒數。

## 操作

- 左鍵拖曳轉動鏡頭，右鍵拖曳平移，滾輪拉近。
- `←` `→`：換一籠
- `P`：後巷
- `S`：大家樂
- 空白鍵：暫停或繼續
- `1` 到 `4`：速度 1×、10×、30×、60×
- `-` `=`：時間減一小時或加一小時
- `N`：自動日夜、固定夜晚、固定白天
- `C`：全景
- `D`：展覽介面。閒置約 15 秒會自動巡遊。也可以按畫面底部的「展覽介面」和「巡遊」。

點蒸籠、茶壺、恆指牌或餐車可看當日分時、近 30 日 K 線和成交額。自選股最多 15 隻；測試選單要在大家樂招牌上連按五次才會出現。

## 檔案

- `src/scene`：茶樓、街道、大家樂
- `src/ui`：畫面上的卡片和按鈕
- `src/services`：報價整理
- `src/config`：股票、時段、顏色
- `server/marketApi.js`：只在本機開發時提供 `/api/market`
- `worker`：放到 Cloudflare 的同一支報價程式

數字可能延遲，只供觀賞，不構成投資建議。
